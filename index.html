Lightshot Desktop

Captura, anotación y grabación de pantalla para evidencias QA

Al abrirla congela la pantalla y muestra una barra de herramientas: se recorta la zona, se anota y el resultado queda copiado al portapapeles listo para pegar en un reporte o un ticket. Hecha para acelerar la documentación de pruebas.

  • Rectángulo, elipse, flecha, texto editable, resaltado y numeración de pasos
  • Desenfoque para ocultar datos sensibles antes de compartir
  • Grabación de pantalla exportada a MKV (remux con FFmpeg, sin recodificar)
  • Ventana transparente sin marco, IPC aislado (contextIsolation, sin nodeIntegration)

Contabilidad IFTAE

Sistema contable de escritorio para una institución educativa

Aplicación instalable, sin internet y sin dependencias externas, que lleva pagos a empleados, ingresos, arqueos de caja e informes. En uso real en el Instituto de Formación Técnica Albert Einstein.

  • Base SQLite local con respaldo automático tras cada movimiento y historial fechado
  • Anulación de movimientos con trazabilidad, recibos numerados, cierre de mes y bitácora de auditoría
  • Contraseñas con PBKDF2 y permisos verificados en el proceso principal
  • Dos compilaciones: Windows 10/11 (SQLite nativo) y Windows 7 de 32 bits (SQLite en WebAssembly), con el mismo archivo de datos
  • Suite de pruebas automatizadas y manual de usuario ilustrado

Validación de datos para migraciones

Calidad de datos · Python

Sistema que valida archivos CSV/Excel antes de una migración masiva: las reglas se escriben en lenguaje natural y se convierten en esquemas de Pandera; el resultado es un reporte navegable con cada error, su fila y su causa.

  • Reglas editables sin tocar código, manual del sistema generado automáticamente
  • Usado sobre bases de decenas de miles de registros (comparendos y acuerdos de pago)
